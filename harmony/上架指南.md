# 华为应用市场（纯血鸿蒙 HarmonyOS NEXT）上架指南

> 本目录 `harmony/` 是完整的鸿蒙原生工程：ArkTS + Web 组件加载本地打包的网站（完全离线）。
> 按本文操作即可构建 HAP 并上架华为应用市场。

---

## 〇、整体流程（按顺序）

```
① 软著申请（约 1-2 个月，可加急）   ← 与 ② 并行
② App 备案（华为 AGC 提交，约 1-2 周） ← 与 ① 并行
③ 下载安装 DevEco Studio（登录华为账号）
④ 打开本工程 → 配置签名（AGC 证书）
⑤ 构建 Release HAP
⑥ AGC 创建应用/版本 → 上传 HAP → 填写材料
⑦ 提交审核（合规检测 + 人工审核，一般 1-7 天）
```

**重要提示**：鸿蒙应用包（HAP）必须用你的华为开发者账号生成的**发布证书**签名才能上架，
本机无法代签。①②③ 需要你本人操作（实名信息），其他步骤可以一起做。

## 一、软件著作权申请（软著）

### 1. 是什么
上架华为应用市场要求提供「计算机软件著作权登记证书」——证明这个软件是你写的。
个人申请**官方免费**（中国版权保护中心），普通通道约 **30-60 个工作日**，加急 1-15 个工作日（代理收费数百元）。

### 2. 怎么申请（个人，官方免费渠道）
1. 注册「中国版权保护中心」账号：https://www.ccopyright.com.cn （需要手机号 + 身份证实名）
2. 在线填写「计算机软件著作权登记申请表」：
   - 软件全称：建议写「**黑白胶片显影时间库软件**」（全称格式：品牌/名称 + 软件/系统 + V版本号）
   - 版本号：V1.0
   - 开发方式：独立开发
   - 软件分类：应用软件
3. 准备材料（在线提交）：
   - 申请表（系统生成）
   - **源代码**：前后各 30 页（每页 50 行），共 60 页 —— 本项目的 `web/index.html` + `data_web.js` 足够凑 60 页（数据部分可删减为说明性代码，也可以直接提交完整代码）
   - **文档**：操作说明书或设计说明书（写 10 页左右：功能介绍 + 界面截图 + 使用方法；我可以帮你起草）
   - 身份证明：身份证正反面
4. 提交后等待审查 → 领取证书（电子证书即可用于上架）

> 如果赶时间：找代理加急（淘宝/知产代理，300-1500 元，1-15 个工作日下证）。也可以先上架"元服务"（部分场景豁免），但不建议绕路。
> 材料起草我可以帮你写：需要的话告诉我，我生成「操作说明书」文档和源代码整理说明。

## 二、App 备案（工信部要求，国内商店上架必须）

1. 登录华为 AGC：https://developer.huawei.com/consumer/cn/service/josp/agc/index.html
2. 控制台 →「App 备案」入口（或创建应用后按提示进入）
3. 填写：主办者信息（个人：身份证）、应用名称、bundleName（com.zyh.filmdevdb）、服务类型
4. 华为会协助提交工信部备案，等待审核（约 1-2 周，短信通知）

> 备案期间可以先做③④⑤，备案通过后再提审。

## 三、安装 DevEco Studio（构建工具）

1. 打开 https://developer.huawei.com/consumer/cn/deveco-studio/ （**需要登录华为账号**才能下载）
2. 下载 macOS 版（x86_64，本机是 Intel Mac），约 2-3GB
3. 解压安装，首次启动登录华为账号，按向导安装 HarmonyOS SDK（API 12 或更高）
4. 本机路径建议：`~/devtools/deveco-studio`（如装别处，构建时用对应路径）

---

## 四、打开工程并配置签名

### 1. 打开工程
DevEco Studio → File → Open → 选择 `harmony/` 目录。
首次打开会提示 Sync（同步依赖），点 Sync 即可。如有 SDK 版本提示（compatibleSdkVersion），按提示选择你安装的版本（5.0.0(12) 或更高）。

### 2. 生成发布证书（AGC）
1. AGC 控制台 → 首页右上角头像 →「用户与访问控制」→「证书管理」
2. 创建**发布证书**（.cer）→ 下载；同时生成配套的 **Key Store 文件（.p12）**，**保存好密码**
3. 「Profile 管理」→ 创建**发布 Profile**（.p7b），关联上面的证书，选择应用 com.zyh.filmdevdb

### 3. 配置到工程
DevEco Studio → File → Project Structure → Signing Configs：
- 勾选 Automatically generate signature（自动模式）**需要先登录账号**；或选 Manual：
  - Store File：.p12 文件 + 密码
  - Key Alias：p12 里的别名
  - Profile：.p7b 文件
- 应用级 build-profile.json5 会自动写入 signingConfigs

## 五、构建 Release HAP

DevEco Studio 菜单 → Build → Build Hap(s)/APP(s) → Build Hap(s) → **Release**。
产物：`entry/build/default/outputs/default/entry-default-signed.hap`

> 命令行方式（可选）：工程目录下
> `hvigorw assembleHap --mode module -p product=default -p buildMode=release --no-daemon`
> （hvigorw 位于 DevEco Studio 的 tools 目录，或通过 ohpm 全局安装）

---

## 六、AGC 创建应用并上传

1. AGC 控制台 →「我的项目」→ 新建项目（如"FilmDev"）
2. 项目内 →「应用」→ 新建应用：
   - 应用名称：黑白胶片显影时间库
   - 包名：com.zyh.filmdevdb
   - 应用分类：工具 → 实用工具
3. 完善应用信息（审核必填）：
   - **应用图标**：本工程 `AppScope/resources/base/media/app_icon.png`（可上传原图）
   - 应用截图：手机 6-8 张（用 DevEco 模拟器或真机跑起来截图；我也可以帮你生成占位图）
   - 应用介绍/更新说明：参考文末模板
   - **隐私政策 URL**：需要托管一个隐私政策网页（GitHub Pages 即可，我可以帮你写一版）
   - 权限声明：本应用**不需要任何敏感权限**（完全离线单机工具），勾选"无"
4. 「版本管理」→ 创建版本 → 上传 `entry-default-signed.hap`
5. 填写版本信息 → 提交审核

## 七、审核与上线

- 华为审核：自动化合规检测（病毒/隐私扫描）+ 人工审核，一般 1-7 个工作日
- 常见驳回点：隐私政策缺失、截图模糊、描述不完整、功能与描述不符 → 按驳回意见修改即可
- 审核通过后自动上架（可设置定时发布）

## 十、常见问题

| 问题 | 解答 |
|---|---|
| 没有软著能先上架吗？ | 不能。华为要求提供软著证书（或登记受理通知书，部分时期可用，建议直接等证书） |
| 备案和软著哪个先？ | 并行进行，互不依赖 |
| bundleName 能改吗？ | 上架后不能改。当前 com.zyh.filmdevdb 已合规 |
| 更新版本流程？ | 改代码 → 重新构建 HAP → AGC 创建新版本上传 → 审核（比首发快） |
| 需要服务器/后端吗？ | 不需要，纯离线应用 |
